Beginner React (No Backend) — Local-Only Quickstart

A copy‑paste tutorial for creating a very simple React app on your computer. No backend—just a local development setup.

1) What you need (one-time)

  • Node.js (LTS) — installs Node + npm. Install from nodejs.org (choose the LTS version).
  • A code editor (e.g., VS Code).

Check versions:

node -v
npm -v

2) Create a fresh React app (with Vite)

# 2.1 Create a new project
npm create vite@latest my-react-app -- --template react

# 2.2 Go into the folder
cd my-react-app

# 2.3 Install dependencies
npm install

# 2.4 Start the local dev server
npm run dev

You should see a URL like http://localhost:5173. Open it in your browser.

What “no server connections” means: You’re not building any API/backend. The dev server only serves your files locally for development. When you build, you get plain static files.

3) Project layout (what each file is)

my-react-app
├─ index.html            # The single HTML page
├─ src/
│  ├─ main.jsx           # Entry: boots React and mounts <App />
│  └─ App.jsx            # Your main React component (edit me!)
├─ package.json          # Scripts & dependencies

4) Minimal React code (copy/paste)

src/main.jsx

import React from 'react'
import { createRoot } from 'react-dom/client'
import App from './App'

createRoot(document.getElementById('root')).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>
)

src/App.jsx

import { useState } from 'react'

export default function App() {
  const [count, setCount] = useState(0)

  return (
    <div style={{ fontFamily: 'system-ui, Arial', padding: 24 }}>
      <h1>Hello, React 👋</h1>
      <p>This is a totally local app. No backend required.</p>

      <button onClick={() => setCount(c => c + 1)}>
        You clicked {count} times
      </button>

      <p style={{ marginTop: 16 }}>
        Edit <code>src/App.jsx</code>, save, and the page reloads instantly.
      </p>
    </div>
  )
}

    npm run build

  • Preview the built app: 
    npm run preview

7) Common issues & quick fixes

  • "vite: command not found" — run npm install; ensure Node is current (node -v ≥ 18 recommended).
  • Port already in use (EADDRINUSE) 
    npm run dev -- --port 5174
  • Dev server stuck / already running — stop with Ctrl + C; on macOS free the port: 
    lsof -i :5173
kill -9 <PID>

8) Optional: one‑file starter UI (paste into App.jsx)

import { useState } from 'react'

export default function App() {
  const [name, setName] = useState('')
  const [todos, setTodos] = useState([])

  const addTodo = () => {
    if (!name.trim()) return
    setTodos(t => [...t, name.trim()])
    setName('')
  }

  return (
    <div style={{ fontFamily: 'system-ui, Arial', padding: 24, maxWidth: 560 }}>
      <h1>React Starter</h1>
      <p>Local-only app. Try adding some items:</p>

      <div style={{ display: 'flex', gap: 8 }}>
        <input
          value={name}
          onChange={e => setName(e.target.value)}
          placeholder="Type an item"
          style={{ flex: 1, padding: 8 }}
        />
        <button onClick={addTodo}>Add</button>
      </div>

      <ul style={{ marginTop: 16 }}>
        {todos.map((t, i) => <li key={i}>{t}</li>)}
      </ul>
    </div>
  )
}
